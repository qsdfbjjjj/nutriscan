# NutriScan — сканер продуктов

Индивидуальный проект по курсу мобильной разработки на Flutter.
Тема №24: **Food Scanner**.

## Цель

Помочь пользователю быстро понять, что он покупает и ест. Достаточно навести камеру
на штрихкод, и приложение покажет состав, калорийность, БЖУ, аллергены и оценку
Nutri-Score. Отсканированные продукты сохраняются в историю и в избранное,
а дневник питания считает калории за день.

## Целевая аудитория

- Люди, которые следят за питанием и считают калории.
- Аллергики и те, кто избегает определённых ингредиентов (глютен, лактоза, орехи).
- Спортсмены, которым важны белки, жиры и углеводы.
- Покупатели, которые хотят сравнивать продукты прямо в магазине.

## Аналоги

| Приложение | Что хорошо | Чего не хватает |
|---|---|---|
| Yuka | Удобная оценка продукта по шкале | Полная версия платная |
| Open Food Facts | Огромная открытая база | Неудобный интерфейс, нет дневника |
| FatSecret | Подробный дневник калорий | Сканер вторичен, много рекламы |

**Чем отличается NutriScan:** бесплатный, сочетает сканер и дневник питания,
предупреждает о личных аллергенах, работает без интернета для уже
отсканированных продуктов, показывает на карте магазины рядом.

## Экраны

1. **Вход / регистрация** — email и Google (Firebase Authentication).
2. **Главная** — калории за сегодня, последние сканирования, кнопка «Сканировать».
3. **Сканер** — камера с распознаванием штрихкода.
4. **Карточка продукта** — фото, состав, КБЖУ, Nutri-Score, аллергены, «добавить в дневник».
5. **Поиск** — поиск продуктов по названию, бесконечная прокрутка.
6. **История и избранное** — все отсканированные и сохранённые продукты.
7. **Дневник питания** — продукты за день, сумма калорий, цель на день.
8. **Карта** — продуктовые магазины рядом, моё местоположение.
9. **Профиль и настройки** — мои аллергены, цель по калориям, тема, язык, выход.

## Планируемый MVP и технологии

| Требование | Как реализуется в NutriScan |
|---|---|
| Архитектура | presentation / domain / data, Repository, DI (get_it) |
| UI | Material 3, светлая и тёмная темы, адаптив под планшет |
| Состояние | Provider (настройки, тема), BLoC (сканирование, поиск, дневник) |
| REST API | [Open Food Facts API](https://world.openfoodfacts.org/data) через dio, без ключа |
| Локальное хранение | SharedPreferences (настройки), Hive (история, избранное, кэш продуктов) |
| Навигация | GoRouter, BottomNavigationBar, redirect для неавторизованных |
| Firebase | Auth, Firestore (дневник и избранное между устройствами), FCM (напоминания) |
| Карты | Google Maps — магазины рядом, geolocator — текущая позиция |
| Нативные функции | Камера (mobile_scanner для штрихкодов), MethodChannel на Kotlin (фонарик / заряд батареи) |
| Тесты и CI | unit, widget, integration; GitHub Actions |
| Публикация | Подписанный AAB, Crashlytics |
